## 项目结构

```
├── .env                        # 环境变量文件
├── bert-base-chinese/          # 本地预训练模型文件夹
├── config.json                 # 项目配置文件
├── Dataloader.py               # 数据预处理模块
├── train.py                    # 训练与评估模块
├── main.py                     # 主程序
├── README.md                   # 项目说明文档
├── train_3k.txt                # 训练集数据（3000条）
├── dev_1k.txt                  # 验证集数据（1000条）
└── test_1k.txt                 # 测试集数据（1000条）
```
